# Experiments

Store experiment configurations, dataset manifests, independently reviewed labels,
and scripts here. Keep large source archives and raw reports in object storage.

Suggested initial evaluation: CWE-78, Python and JavaScript/TypeScript.
Pin repository revision, tool versions, rule/query packs and scan configuration.
Keep a vulnerability's original, patched and derived cases in the same data split.

Compare Semgrep, CodeQL, a simple combination, then the evidence-based triage pipeline.
Report detection metrics separately from matching/deduplication metrics.
Tool disagreement is not a ground-truth label; no CodeQL alert does not prove safety.
