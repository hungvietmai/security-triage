# CWE-22 safety-evidence pack v0.2 (worker copy)

The scan worker runs these queries for the `path-traversal-v0.2` profile. Every file is a
byte-identical copy of the evaluated research pack; `experiments/tests/test_product_pack.py`
fails if any copy drifts.

| File | Source |
|---|---|
| `SafetyEvidence.qll`, `qlpack.yml`, `table/Evidence.ql` | `experiments/owasp-bp-pilot/ql_v02/`, pinned by `FREEZE_v0.2_postformat.sha256` |
| `queries/cwe22_none.ql`, `queries/cwe22_all.ql` | Generated by the frozen `ql_v02/gen.py`; hashes recorded in `experiments/wave-c/toolchain.lock.json` |
| `codeql-pack.lock.yml` | `experiments/wave-c/pack-locks/v02.lock.yml` |

- `cwe22_none.ql` (`st/cwe-22/none`) is the default CodeQL path-injection query. Its alerts
  are the baseline.
- `cwe22_all.ql` (`st/cwe-22/all`) adds every v0.2 safety-evidence barrier and sink
  exclusion. Its alerts are always a subset of the baseline.
- A baseline alert with no `all` alert at the same location is hidden by safety evidence.
  It is kept and ranked last, never deleted.

Do not edit these files. A new evidence version needs a new pack directory and profile.
